## Chức năng chính
* Quản lý tour, lộ trình (nơi dừng chân, phương tiện, khách sạn), điểm tham quan
* Lập phiếu đăng ký theo đoàn (> 12 người, đặt cọc, danh sách bảo hiểm)
* Lên lịch chuyến và bán vé cho khách lẻ (1–12 người)
* Phân công hướng dẫn viên không trùng lịch
* Khởi hành / kết thúc / hủy tour, phiếu khảo sát
* Bảng lương tháng

## Đối tượng sử dụng
* Nhân viên bán tour: lập phiếu, bán vé, ghi khảo sát
* Điều hành tour: tour, lịch chuyến, phân công
* Kế toán: quyết toán đoàn, lương

## Yêu cầu phần mềm
* Windows 10
* .NET Framework 4.7.2, Visual Studio 2022
* Oracle Database 19c
